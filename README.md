 Eddie's Cut — Premium Barber & Hair Salon

A production-ready, ultra-performant, and visually stunning modern web application built for **Eddie's Cut**, an established luxury hair salon located in Hellerup, Denmark (Est. 2006). This project completely overhauls the legacy web presence into a high-end, conversion-focused single-page application (SPA).

---

🎨 Premium Features & Experience

Tailwind v4 Design System:** Completely customized brand token architecture featuring a luxury Danish palette: Deep Organic Olive Green, Dark Charcoal Slate, and Stark Clean Off-White.
Staggered Typography Animations:** Custom letter-by-letter entrance animations and dynamic wave hover-states running on the main branding typography using `framer-motion`.
Dynamic Scroll-Spy Navigation:** Seamless pixel-perfect section jumping with automatic active-state underlines that track user placement on screen natively while accommodating sticky navbar header heights.
Sleek Interactive Pricing Accordions:** Combines extensive treatment lists into highly responsive collapsible dropdown cards to increase engagement and prevent long-scroll data fatigue.
Overlapping Brand Photography:** High-end asymmetric imagery configuration layout in the "Om Os" section highlighting Eddie's real workspace and salon identity.
Live Copenhagen Time Engine:** Integrated hybrid client/server ticking clock displaying real-time local Danish time with a continuous pulsing visual indicator dot.
WCAG 2.2 Accessibility Standards:** Defensive layout implementations including focus-visible indicator rings for keyboard navigators, dedicated ARIA labels for screen readers, and programmatic semantic tags.
Defensive Mobile Responsiveness:** Clean layout strategies eliminating mobile scaling traps, text overlaps, or un-intentional image truncation under variable device viewport constraints.

---

## 🛠️ Tech Stack

Framework: Next.js (App Router Architecture)
Compiler Engine:** Turbopack (Ultra-fast incremental local bundles)
Styling Engine:** Tailwind CSS v4 Engine
Animation Engine:** Framer Motion (Hardware-accelerated web transitions)
Iconography:** Lucide React Vectors
